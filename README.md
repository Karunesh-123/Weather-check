# Weather Check

A weather app built with React to check current weather and forecasts for different cities.

## Features

- Search weather by city
- Get weather using current location
- View current weather and 7-day forecast
- Switch between Celsius and Fahrenheit
- Save favourite cities
- View recently searched cities
- Compare weather between two cities, including temperature and weather conditions
- View detailed weather information for a city
- Switch between dark and light themes
- Responsive design for mobile and desktop
- Loading indicators and error messages

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Build Tool:** Vite
- **UI Framework:** Bootstrap
- **API:** Open-Meteo API
- **Data Storage:** Browser localStorage
- **Version Control:** Git and GitHub
